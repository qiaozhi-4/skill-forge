# Kotlin 注释规则

Kotlin 注释不仅按单行或多行选择语法，还要结合声明可见性、类型系统、协程模型和 Java 互操作边界判断注释内容。注释应说明读者无法仅从 Kotlin 签名可靠推断的意图、约束和风险。

## 注释对象与内容

- **公共类、接口、对象、枚举和密封类型**：优先使用 KDoc，说明不变量、状态集合、扩展方式、序列化/反序列化约束和生命周期。
- **函数、构造器和扩展函数**：每个声明都使用 KDoc，不因可见性或签名显而易见而省略；说明接收者语义、参数约束、默认值的业务含义、返回值状态、异常、线程安全、挂起/恢复边界和资源生命周期。
- **属性、字段和常量**：类成员属性、顶层属性、常量和每个枚举项都在声明上方使用 `///`，说明业务含义、单位、取值范围、默认值、可变性、延迟初始化、缓存策略或所有权。
- **自定义 getter 属性**：计算属性仍然是属性，`///` 应放在 `val`/`var` 声明上方，说明读取结果的含义；不要把属性注释放到 `get()` 上方。
- **分支、集合转换和 DSL 逻辑**：只说明业务规则、性能取舍、求值顺序或易错边界，不要逐行解释表达式。
- **TODO 和 FIXME**：说明未完成的原因、风险和完成判据，避免留下没有行动方向的待办。

本节示例只展示部分写法和位置，不是需要注释的完整清单；声明注释义务按上方规则执行，不能因为示例未展示某种声明或名称显而易见而省略。

## 注释形式

- 单行说明、TODO、分支说明和语句行尾注释统一使用 `///`，不要使用 `//`；行尾注释仅在说明不可见的业务原因或边界时使用。
- 属性、字段、常量和枚举项的简短说明放在对应声明上方，使用 `///`。
- 公共 API 或需要生成文档的声明使用 `/** ... */`（KDoc）；一行无法容纳且不需要生成文档时才使用 `/* ... */` 短块注释。
- 只有内容确实需要块结构时才使用 `/* ... */`，不要用块注释堆叠多条单行说明。

## 函数与构造器

- 每个函数、构造器或扩展函数的 KDoc 紧邻声明上方，完整列出适用的 `@param`、`@return` 和 `@throws`；无参数时省略 `@param`，返回类型为 `Unit` 时省略 `@return`。
- 函数体内只在逻辑复杂或较长、需要解释原因或边界时，才在对应逻辑上方使用 `///`；简单逻辑不添加函数体内注释。

## Kotlin 特有约束

- 涉及可空类型、平台类型、强制解包 `!!`、智能转换或泛型约束时，说明空值来源、合法范围和失败行为。
- 涉及 `suspend` 函数、协程、`Flow`、回调或调度器时，说明执行上下文、取消传播、冷/热流语义、背压和线程安全边界。
- 涉及 `val`/`var`、委托属性、懒加载、缓存或共享可变状态时，说明初始化时机、可见性、失效条件和并发要求。
- 涉及内联函数、`reified` 类型参数、操作符重载、DSL 标记或密封层级时，记录调用限制和不能随意改写的原因。
- 涉及 Java 互操作、注解、反射、序列化或版本兼容时，说明平台差异、生成代码约束和运行时要求。
- 类型、函数和属性引用优先使用 KDoc 可解析的 `[TypeName]`、`[functionName]` 或 `[propertyName]` 形式，并确保名称在当前解析范围内有效。

## 维护检查

- 修改可空性、协程上下文、状态集合、默认参数、异常行为或 Java 互操作契约时，同步更新相关注释。
- 检查 KDoc 链接和标签是否仍能解析，避免复制容易过期的实现细节。
- 完成格式检查以及项目已有的 Dokka、编译器或静态分析检查。

## 示例

下面的示例展示类、属性和公共函数如何分别记录业务约束；属性注释说明其约束，不重复属性名。

```kotlin
/**
 * 记录批量导入任务的进度，并限制进度只能单调增加。
 *
 * @param jobId 非空的导入任务标识
 */
class ImportJob(jobId: String) {
    /// 导入任务的唯一标识，创建后不可变。
    val id: String = jobId.also {
        require(it.isNotBlank()) { "jobId must not be blank" }
    }

    /// 当前进度百分比，范围为 0..100，仅通过 updateProgress 修改。
    var progress: Int = 0
        private set

    /**
     * 更新导入进度。
     *
     * @param value 新的进度百分比，不能小于当前进度
     * @throws IllegalArgumentException 当进度超出 0..100 或回退时抛出
     */
    fun updateProgress(value: Int) {
        require(value in 0..100) { "progress must be between 0 and 100" }
        require(value >= progress) { "progress cannot move backwards" }
        progress = value
    }
}
```

计算属性的注释放在 `val`/`var` 声明上方，覆盖属性及其自定义 getter：

```kotlin
class DecodedConfigView(private val decoded: DecodedConfig) {
    /// 解码后的延迟时长，单位为毫秒。
    val delay: Long
        get() = decoded.config.delayMillis.toLong()
}
```

无参数或 `Unit` 返回值时只写适用的 KDoc 标签；顶层 `object` 和枚举也应说明用途，成员常量和枚举项使用 `///`：

```kotlin
/**
 * 返回当前运行模式。
 * @return 当前模式编号。
 */
fun currentMode(): Int = 0

/** 清空临时缓存。 */
fun clearCache() {}

/** 配置读取状态。 */
enum class ConfigStatus {
    /// 配置读取成功。
    Ready,
    /// 配置内容无效。
    Invalid
}

/** 配置模块的默认值。 */
object ConfigDefaults {
    /// 首次连接前允许的重试次数。
    const val MAX_RETRIES = 3
}
```
