# JavaScript 注释规则

JavaScript 注释应说明读者无法仅从函数行为、模块边界或对象结构可靠推断的业务意图、调用约束和风险。

## 注释对象与内容

- **函数、方法和构造器**：每个声明都在上方使用 JSDoc，不因可见性或签名显而易见而省略；说明参数、返回值、异常、状态变化和资源生命周期等契约。
- **类和模块**：为有公共职责或稳定调用边界的类、模块添加 JSDoc，说明用途、生命周期和扩展限制。JavaScript 没有 `namespace` 声明；需要说明模块职责时，可在文件顶部使用 `@module`。
- **字段、常量和枚举式对象**：类字段、常量、对象常量及其枚举式成员都在声明上方使用 `///`，说明含义、取值范围、默认值、可变性或所有权。
- **函数体内逻辑**：只在逻辑复杂或较长、需要解释原因或边界时，在对应逻辑上方使用 `///`；简单逻辑不添加函数体内注释。
- **TODO 和 FIXME**：说明未完成的原因、风险和完成判据，避免留下无法行动的空泛待办。

本节示例只展示部分写法和位置，不是需要注释的完整清单；声明注释义务按上方规则执行，不能因为示例未展示某种声明或名称显而易见而省略。

## 注释形式

- 普通单行说明、TODO、分支说明和行尾注释使用 `///`，不要使用 `//`；行尾注释只用于说明不可见的业务原因或边界。
- 函数、方法、构造器、类和模块的契约文档使用 `/** ... */`（JSDoc）。
- 只有需要块结构且不属于 API 文档时才使用 `/* ... */`。

## 函数与成员注释

- 每个函数、方法或构造器的 JSDoc 紧邻声明上方；每个参数使用 `@param`，有有意义的返回值时使用 `@returns`，并按需说明 `@throws`。
- 没有参数时省略 `@param`；函数不返回有意义的值时省略 `@returns`。
- 函数级说明放在声明上方，不放入函数体；函数体内只为复杂或较长的局部逻辑添加注释。
- 字段、常量和对象成员的 `///` 注释放在对应声明上方，保持紧邻。

## JavaScript 特有约束

- 涉及 `null`、`undefined`、缺省属性或可选参数时，说明缺失值的来源和调用方可观察到的行为。
- 涉及 Promise、事件回调、计时器或共享状态时，说明完成时机、回调顺序、取消方式和并发边界。
- 涉及闭包、`this` 绑定、原型、代理或 getter/setter 时，说明生命周期、绑定对象和可观察副作用。
- JavaScript 没有原生枚举声明；使用对象表示固定状态集合时，说明对象不可变性和每个成员的含义。
- JavaScript 没有 TypeScript 的 `type` 和 `interface` 声明；需要描述对象形状时，可在 JSDoc `@typedef` 中使用 `@property`，不要把这种类型说明混同于运行时对象字段注释。

## 示例

```javascript
/**
 * 提供缓存访问与状态查询。
 * @module cache
 */

/** 保存运行期间的临时缓存。 */
export class CacheStore {
    /// 缓存只在当前实例生命周期内有效。
    #entries = new Map();

    /**
     * 查询缓存项。
     * @param {string} key 缓存键。
     * @returns {unknown | undefined} 缓存值；键不存在时返回 undefined。
     */
    get(key) {
        return this.#entries.get(key);
    }
}

/// 当前支持的缓存状态及其稳定编码。
export const CacheState = Object.freeze({
    /// 尚未加载缓存。
    EMPTY: "empty",
    /// 缓存已加载。
    READY: "ready",
});

/** 切换当前运行模式。
 * @param {string} mode 要切换到的模式。
 */
export function setMode(mode) {}

/**
 * 返回当前缓存项数量。
 * @returns {number} 当前缓存项数量。
 */
export function cacheSize() {
    return 0;
}

/** 清空当前缓存。 */
export function clearCache() {}
```
