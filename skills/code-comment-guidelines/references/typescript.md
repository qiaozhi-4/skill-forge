# TypeScript 注释规则

TypeScript 注释应区分运行时行为与静态类型契约；函数契约、类型声明、字段和枚举成员按各自形式注释。

## 注释对象与内容

- **函数、方法和构造器**：每个声明都在上方使用 TSDoc，不因可见性或签名显而易见而省略；说明参数、返回值、异常、状态变化和资源生命周期等契约。
- **类、接口和类型别名**：对有公共职责或稳定约束的声明使用 `/** ... */`，说明职责、不变量和扩展限制。
- **字段和类型成员**：类字段、接口属性、对象类型成员、常量和每个枚举成员都在声明上方使用 `///`，说明业务含义、单位、取值范围、默认值、可变性或所有权。
- **枚举和命名空间**：枚举声明、每个枚举成员和命名空间声明都使用贴近声明的 `///` 说明其用途。
- **函数体内逻辑**：只在逻辑复杂或较长、需要解释原因或边界时，在对应逻辑上方使用 `///`；简单逻辑不添加函数体内注释。

本节示例只展示部分写法和位置，不是需要注释的完整清单；声明注释义务按上方规则执行，不能因为示例未展示某种声明或名称显而易见而省略。

## 注释形式

- 普通单行说明、TODO、分支说明和行尾注释使用 `///`，不要使用 `//`；行尾注释只用于说明不可见的业务原因或边界。
- 函数、方法、构造器、类、接口和类型别名的契约文档使用 `/** ... */`（TSDoc）。
- TypeScript 的 `/// <reference ... />` 等三斜线指令具有编译语义，应按需保留，不能改写成普通说明注释。
- 只有需要块结构且不属于 API 文档时才使用 `/* ... */`。

## 函数与成员注释

- 每个函数、方法或构造器的 TSDoc 紧邻声明上方；每个参数使用 `@param`，非 `void` 返回值使用 `@returns`，并按需说明 `@throws`。
- 没有参数时省略 `@param`；返回类型为 `void` 时省略 `@returns`。异步函数若返回 `Promise<T>`，应描述 Promise 的完成结果和拒绝条件。
- 函数级说明放在声明上方，不放入函数体；函数体内只为复杂或较长的局部逻辑添加注释。
- 类字段和接口、对象类型中的属性使用 `///` 注释并紧贴对应成员。

## TypeScript 特有约束

- `type` 和 `interface` 的声明本身用 TSDoc 说明类型职责；其成员逐项使用 `///`，不要把成员约束只写在类型整体说明里。
- `enum` 声明及每个枚举成员都使用 `///`；如果值会序列化或写入外部协议，说明稳定性和兼容约束。
- `namespace` 声明用 `///` 说明其组织的功能边界，内部导出字段仍分别使用 `///`。
- 泛型、判别联合、条件类型、类型谓词、断言和 `any` 边界不明显时，说明调用方必须满足的约束及失去类型保证的范围。
- 涉及 `null`、`undefined`、可选属性、类型窄化或非空断言时，说明空值来源、合法范围和失败行为。
- 涉及 Promise、事件回调、取消信号或共享状态时，说明完成时机、错误传播和并发边界。

## 维护检查

- 修改类型成员、函数签名、空值语义、异步行为或错误传播时，同步更新相关注释和标签。
- 检查文档是否与实际类型、实现和编译器行为一致；保留有实际用途的三斜线指令。
- 完成项目已有的 TypeScript 编译、文档生成或静态分析检查。

## 示例

```typescript
/** 运行任务时可选择的模式。 */
export type Mode = "automatic" | "manual";

/** 缓存项的键和值。 */
export interface CacheEntry {
    /// 键在缓存命名空间内唯一。
    key: string;
    /// 值只在当前版本的缓存格式中有效。
    value: unknown;
}

/// 当前支持的加载状态。
export enum LoadState {
    /// 尚未开始加载。
    Idle = "idle",
    /// 加载已完成。
    Ready = "ready",
}

/// 初次连接失败后允许的重试次数。
export const MAX_RETRIES = 3;

/// 提供与缓存版本相关的状态。
export namespace Cache {
    /// 当前缓存格式版本，升级时需要同步迁移旧数据。
    export const version = 2;
}

/** 设置当前运行模式。
 * @param mode 要切换到的模式。
 */
export function setMode(mode: Mode): void {}

/**
 * 返回当前运行模式。
 * @returns 当前模式。
 */
export function currentMode(): Mode {
    return "automatic";
}

/** 清空当前缓存。 */
export function clearCache(): void {}
```
